# Alterz

> « Tous les sons que tout le monde ecoute. »

Grande radio commerciale internationale : pop, electro-pop, tubes viraux. La plus propre, la plus formatee et la plus chargee en publicites.

## Ou deposer les fichiers

- `Musiques/` : les morceaux diffuses hors emission.
- `Jingles/` : habillage court.
- `Publicites/` : pubs et annonces.
- `Emissions/Starzone/` : un fichier par episode.

Le nom des fichiers est libre : le jeu detecte tout ce qui est depose ici.
Pour creer une autre emission, ajoute simplement un dossier dans `Emissions/`.

Voir `public/musique/radio/README.md` pour la convention complete et
`docs/Documentations RADIO/Identite des radios du jeu.pdf` pour l'identite detaillee.
