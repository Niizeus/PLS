# Convertisseur WAV vers OGG

Petit outil Windows pour convertir une ou plusieurs pistes `.wav` en `.ogg` Vorbis.

## Utilisation rapide

1. Double-clique sur `Convertir WAV en OGG.bat`.
2. Selectionne un ou plusieurs fichiers `.wav`.
3. Les fichiers `.ogg` sont crees dans le dossier `Downloads` / `Telechargements`.

Tu peux aussi glisser-deposer des fichiers `.wav`, ou un dossier contenant des `.wav`, directement sur `Convertir WAV en OGG.bat`.

## Dependances

L'outil utilise `ffmpeg`. S'il manque sur le PC, le script propose de l'installer avec `winget`.

La qualite par defaut est `6 / 10`, un bon compromis pour les musiques du jeu.
