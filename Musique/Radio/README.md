# Dossier de travail radio

Ce dossier peut servir a preparer les musiques, jingles, pubs et emissions.

Pour que le jeu les lise directement pendant les tests, mets aussi les `.wav` dans :

```text
public/musique/radio/
```

Structure prevue par station :

```text
RXX/
  Musiques/
  Jingles/
  Publicites/
  Emissions/
    Podcast_Du_Soir/
```

Convention de noms : `RXX-TXX.wav` pour les musiques, `RXX-JXX.wav` pour les jingles,
`RXX-PXX.wav` pour les pubs et `RXX-EXX.wav` pour les emissions.
